# ServicesLocaux - Site Vitrine

## 📝 Description
Site vitrine développé pour une activité locale, présentant les services de l'entreprise. Projet réalisé dans le cadre d'un développement personnel (Juillet 2024 - Septembre 2024).

## 🚀 Technologies utilisées
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Design Responsive

## ✨ Fonctionnalités
- Navigation responsive avec menu burger
- Animations au scroll
- Formulaire de contact avec validation
- Design moderne et épuré
- Compatible mobile, tablette et desktop
